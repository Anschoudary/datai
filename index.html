Live Demos

Auto Plotting

Automatically suggest the best plots for your data.

from datai.auto_plot import auto_plot
import pandas as pd

data = {'Category': ['A', 'B', 'A', 'C', 'B', 'A'],
        'Value': [10, 15, 7, 12, 9, 11],
        'Group': ['X', 'Y', 'X', 'Y', 'X', 'Y']}
df = pd.DataFrame(data)
auto_plot(df)

Sound Analysis

Visualize waveform, FFT and spectrogram with ease

import numpy as np
import matplotlib.pyplot as plt
from datai import sound_visualization

# Generate a simple signal (e.g., a sine wave)
time, sine_wave = sound_visualization.generate_sine_wave(frequency=1, duration=2, sample_rate=8000)

# Visualize the waveform
sound_visualization.visualize_waveform(signal=sine_wave, sample_rate=8000, title='Simple Waveform', file_path="wave.png")

Getting Started

Installation

Install Datai using pip:

pip install datai

Basic Usage

Create a scatter plot using the built-in scatter_plot function:

from datai.visualization import scatter_plot
scatter_plot(data="iris", x="sepal_length", y="sepal_width", title="Iris Sepal Length vs. Width")

Data Cleaning

Handle missing values in your DataFrame using the handle_missing_values function:

from datai.data_cleaning import handle_missing_values
import pandas as pd
import numpy as np

# Sample DataFrame with missing values
data = {'col1': [1, 2, np.nan, 4], 'col2': [5, np.nan, 7, 8]}
df = pd.DataFrame(data)

df_clean = handle_missing_values(df, method='mean')
print(df_clean)

Validating Data Sets

Before working on dataset, one should validate it using the method validate_dataset

from datai.utils import validate_dataset
import pandas as pd

data = {'Name': ['Alice', 'Bob', 'Charlie'], 'Age': [25, 30, 35]}
df = pd.DataFrame(data)

is_valid = validate_dataset(df)
print(f"Dataset is valid: {is_valid}")
